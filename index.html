About

How I work & learn

Personal notes on my journey with software and systems.

Curiosity first

I spend my free time setting up window managers, modifying Android overlays, and playing with system configurations. I learn how software works by digging into the settings, testing its limits, and rebuilding it.

Visual focus

Design isn't an afterthought. I care about layout spacing, clear typography, and subtle transitions. If a tool works well, it should look and feel just as good.

Independent builds

I prefer building focused tools for personal use and sharing them online. No corporate checklists—just software crafted because it's interesting to make.
